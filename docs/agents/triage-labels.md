# Triage labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | The issue needs more information from its reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | The issue needs human implementation. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

When a skill names a triage role, use its matching GitHub label.
