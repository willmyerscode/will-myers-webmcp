# Domain docs

This is a single-context repository.

Before codebase work, read these files when they exist:

- `CONTEXT.md` at the repository root.
- Relevant decisions under `docs/adr/`.

If these files do not exist, continue without an error. Domain-modeling skills create them only when the project needs them.

Use the terms defined in `CONTEXT.md`. If work conflicts with an architectural decision, report the conflict and name the ADR.
